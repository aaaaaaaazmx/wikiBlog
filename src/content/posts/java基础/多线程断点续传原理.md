# 多线程断点续传原理

在本地下载过程中要使用数据库**实时存储**到底**存储到文件的哪个位置了**，这样点击开始继续传递时，才能通过HTTP的GET请求中的

`setRequestProperty("Range","bytes=startIndex-endIndex");`

方法可以告诉服务器，数据从哪里开始，到哪里结束。同时在本地的文件写入时，RandomAccessFile的seek()方法也支持在文件中的任意位置进行写入操作。同时通过广播或事件总线机制将子线程的进度告诉Activity的进度条。关于断线续传的HTTP状态码是206，即HttpStatus.SC_PARTIAL_CONTENT。
