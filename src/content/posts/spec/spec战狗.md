# Spectra 战狗（WARDOGS）使用教程

> 根据《Spectra 系列 DMA 通用教程》整理。原教程截图主要以 Call of Duty（COD）为例，本文按战狗整理操作入口；战狗的具体版本、平台选项和运行提示，以实际界面为准。

## 一、使用前准备

- 准备 Spectra 登录器及对应产品的有效卡密。
- 确认要使用的产品是 **WARDOGS（战狗）**，不要误选截图中的 COD。
- DMA 硬件安装、接线、驱动和固件配置；这些准备工作需另行参考设备说明。
- 仅运行来源可信的软件，不要公开卡密；使用前了解游戏规则及账号风险。

## 二、以管理员身份运行登录器

1. 打开 Spectra 登录器所在文件夹。
2. 右键登录器程序，选择 **以管理员身份运行**。
3. 在产品列表中找到 **WARDOGS**。
4. 点击该产品旁的 **Open**，进入对应产品的版本界面。

## 三、安装并启动最新版本

1. 在版本列表中选择标有 **LATEST** 的最新版本。
2. 点击 **Install & Launch**，等待下载安装完成。
3. 安装完成后，按原教程点击 **Launch** 启动。

> 截图中的 `0.0.15` 是当时 COD 的示例版本，不代表战狗当前版本，请勿照抄版本号。

### 常见按钮说明

| 按钮 | 含义 |
| --- | --- |
| Open | 打开对应产品的版本界面 |
| Install & Launch | 安装并启动 |
| Launch | 启动已安装的版本 |
| Open folder | 打开文件夹 |

## 四、输入卡密

1. 启动后会出现控制台窗口。
2. 等待出现 **Please enter your key** 提示。
3. 输入自己的卡密，按 **Enter（回车）** 提交。
4. 查看验证结果，再按窗口提示继续。

**不要使用原教程截图中的示例卡密，也不要将自己的卡密发到公开群聊或截图中。**

## 五、选择游戏平台

如果程序提示选择平台：

1. 查看当前窗口列出的平台名称和对应编号。
2. 输入自己实际使用的平台编号。
3. 按 **Enter（回车）** 确认。

> 原教程 COD 示例列出了 Steam、Xbox、Battle.net。它们不是已确认的战狗平台列表，编号和可用选项请以战狗实际窗口为准。

## 六、处理 Microsoft 符号许可弹窗

原教程中会弹出标题为 **Microsoft Internet Symbol Store** 的许可窗口。

1. 阅读窗口中的许可条款。
2. 若同意条款，点击 **Yes** 继续。
3. 返回控制台查看后续运行提示。

如果没有出现该窗口，继续按实际程序提示操作即可。

## 七、确认状态后启动游戏

原教程给出的顺序是：**注入成功后，再启动游戏**。

1. 查看控制台，确认当前状态及是否存在报错。
2. 按程序提示确认 DMA 设备已连接。
3. 确认满足启动条件后，启动 **战狗（WARDOGS）**。

> 注意：原 PDF 最后一张截图仍有等待连接 DMA 设备、启动游戏的提示，且截图中出现过 `Bad PCIe TLP received. Should not happen!`。不能仅凭窗口打开或出现 `INFO` 就判断注入成功；战狗的成功提示需以实际程序为准。

## 八、遇到问题先检查什么

以下为补充检查建议，并非原 PDF 提供的故障修复方案。

### 找不到启动按钮

- 确认已进入 **WARDOGS** 的版本界面。
- 检查所选版本是否安装完成；未安装时通常显示 **Install & Launch**，安装后显示 **Launch**。

### 卡密验证未通过

- 检查是否输入完整，是否误带空格或换行。
- 核对卡密对应的产品及有效期。
- 仍无法验证时，联系提供方核实，不要公开完整卡密。

### 一直等待 DMA 设备或出现设备报错

- 根据设备说明检查供电、连接及必要配置。
- 不要把等待信息当作成功提示。
- 保存报错文字并联系设备或软件提供方，发送截图前遮盖卡密等敏感信息。
- 原教程未给出上述 PCIe 报错的解决方法，不建议盲目修改固件或系统设置。

## 快速流程

**管理员运行登录器 → WARDOGS / Open → 选择最新版本 → Install & Launch → 安装完成后 Launch → 输入卡密并回车 → 按提示选择平台 → 阅读并确认符号许可（如出现）→ 确认运行状态 → 启动游戏。**
